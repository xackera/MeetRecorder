# Meet Recorder

Chrome-расширение (Manifest V3) для записи **видео и звука** вкладки с Google Meet
(или любого сайта) в файл `.webm`. Может подмешивать ваш микрофон.

## Установка

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Откройте `chrome://extensions/`, включите **«Режим разработчика»**.
3. **«Загрузить распакованное расширение»** → выберите папку проекта.

## Использование

1. На вкладке Meet нажмите иконку расширения → **«Начать запись»**.
2. При первом запуске с микрофоном выдайте доступ на открывшейся вкладке.
3. **«Остановить и сохранить»** → файл `.webm` сохранится через диалог загрузки.

Конвертация в MP4: `ffmpeg -i запись.webm -c:v libx264 -c:a aac out.mp4`

## Структура

```
manifest.json       — манифест
background.js        — service worker: оркестрация и скачивание
offscreen.html/.js   — захват потока и запись (MediaRecorder)
popup.html/.js       — интерфейс старт/стоп
permission.html/.js  — доступ к микрофону
icons/               — иконки
```
